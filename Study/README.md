# Study folder map

Organized into five folders by how you actually use each file.

## Guides/
Polished, copy-paste and print ready handbooks (Word and PDF). These are the finished deliverables you open and use.
- `Job_Search_Playbook.docx` — LinkedIn, salary anchor, referral routine, networking templates, 30-day sprint.
- `Personal_Operating_Workbook.docx` — your operating system: mind manual, anchors, study, fitness, decision framework, job search.
- `Daily_Interview_Rehearsal_Workbook.docx` — 22-story bank, 11-day rotation, mock question bank, tough-question scripts, morning-of checklist.
- `Interview_Story_Card.docx` / `.pdf` — one-page pressure card.
- `IT_Learning_Path_and_Schedule.docx` — the sequenced cert and skills roadmap.
- `IT_Cheat_Sheets.docx` / `.pdf` — quick-reference sheets.

## Flashcards/
Everything for Anki. Import `IT_Flashcards.apkg` for one-tap load; the `.txt` files are the editable source per deck (plus `IT_Flashcards_ALL.txt` combined).

## Notes/
Markdown reading and reference material: `Daily_Companion.md` (open daily), plus the deep-dive and analysis notes (cloud/DevOps, fitness, how you think, practical skills, supply chain, transcript analyses, and the Job Search Playbook source).

## Interview_Story_System/
Working docs behind the story bank (drafts, tightening, improvement plan, master plan). Reference, not daily use.

## Codex_Specs/
Implementation specs and plans handed to Codex for the resume-system pipeline. Internal build notes.

---
*Reasoning: the clutter was 22 flashcard files and 20-plus markdown files sitting next to the finished handbooks. Splitting by use (use it = Guides, drill it = Flashcards, read it = Notes, build it = Codex_Specs / Interview_Story_System) makes the folder scannable and keeps daily-use files apart from internal build notes.*
